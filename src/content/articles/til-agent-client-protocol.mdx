I learned about the [Agent Client Protocol (ACP)](https://agentclientprotocol.com/get-started/introduction) while using tern. It gives editors and coding agents a common language, so developers don't need to build a custom integration for every editor-agent pair.

It's a similar idea to LSP: an editor implements the protocol and can work with agents that support it, instead of handling each one differently.

Herdr is my daily driver, so I'm now exploring how ACP could improve the experience there. I'm still figuring out what that integration would look like.
